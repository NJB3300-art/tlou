Help!

Setting up The Last of Us Remastered on an Xbox in Developer Mode, with the UWP port of ravencaio/tlou-remastered-pc. No game files are included: you need your own dump of the game.

Video guide

3½ minutes, narrated. Captions are on by default: use the CC button in the player to turn them off. Download the video · captions (.vtt)

What you need

  • An Xbox Series X or S in Developer Mode
  • A Windows PC with Python 3.10 or newer
  • Your own dump of CUSA00552 and its update 1.11
  • A USB drive formatted exFAT or NTFS

Step by step

  1. Download the release. On the releases page, take the newest one: tlou-uwp-xbox-….zip (the app) and tlou-uwp-stage-kit-….zip (the PC tools).
  2. Prepare the game on the PC. Unzip the stage kit. Put your CUSA00552 folder and the update as CUSA00552-patch next to it, then double-click Stage-TLOU-Xbox.cmd. It writes a folder called uwp-stage. 
    Games\
├─ CUSA00552\              your game
├─ CUSA00552-patch\        update 1.11
└─ tlou-uwp-stage-kit\
   ├─ Stage-TLOU-Xbox.cmd  double-click
   └─ uwp-stage\           written by the kit
    Settings that change the game itself are chosen here. For example, run set TLOU_RESOLUTION=1920x1080 in the same window first.
  3. Copy everything to the USB drive, in a folder named TLOU, and rename uwp-stage to stage: 
    E:\TLOU\
├─ CUSA00552\
├─ CUSA00552-patch\
└─ stage\          (the contents of uwp-stage)
    Plug the drive into the Xbox. The app looks for a TLOU folder on every drive.
  4. Install the app with Device Portal. Dev Home on the Xbox shows the Device Portal address; open it in a browser on your PC. Under My games & apps choose Add, select the .msix from the Xbox zip, add Microsoft.VCLibs.x64.14.00.appx as its dependency, and start the install.
  5. Set it as a Game, then play. In Dev Home, open the app's details and set App type to Game. Games get much more memory, and the game needs about 6 GB. Start the app: the launcher shows what it found. A changes a setting; Play or the Menu button starts the game.

If something goes wrong

What you seeWhat to do
Nothing happens when the app starts Install the newest release (v0.2.2-uwp.1 or later fixed the app closing at launch). Then read app.log.
The game closes the app Open the app again: it shows the end of boot.log. The full file says why.
“gow3-runtime.dll could not be loaded (error 126)” A DLL the game needs is missing on the console. runtime-imports.txt in the Xbox zip lists them all.
Launcher says stage\boot.json missing Run Stage-TLOU-Xbox.cmd again and copy uwp-stage to TLOU\stage.

Where the logs are

Device Portal → File explorer → LocalAppData → the app → LocalState: app.log (the app), boot.log (the game), your saves, tlou.ini and the shader cache.

Known limit: Vulkan on Xbox

The game draws with Vulkan, and the Xbox has no Vulkan driver of its own. Until a driver for UWP is added to the package (for example Mesa's Vulkan-on-Direct3D 12 driver), the game may stop when it starts its renderer. boot.log then says so.
